# `summarizeTransports(services)` — сводка для бут-лога

## Зачем

Потребители на буте логируют сводку «какие сервисы/тулы на каких транспортах»
(HTTP / MCP / AGENT / CLI, комбинации expose) — и каждый ковыряет `ServiceDef`
руками. Комбинаторика expose (default-on для MCP/AGENT, opt-in CLI, multipart
skip) — знание фреймворка, ему и жить в пакете.

## Идея

`summarizeTransports(services)` → структура (счётчики по транспортам +
разбивка по сервисам), которую приложение рендерит в свой лог само. Никакого
встроенного логгера — только данные.

После появления `listToolNames` (задача 2026-07-09) — возможно, просто
надстройка над ним + HTTP-срез. Проверить перед реализацией, не схлопнуть ли
в один модуль.

## Приоритет

Низкий — дёшево, но и боль копеечная. Делать попутно с соседней задачей по
tools-слою.
