# Документационный сайт

## Зачем

Сейчас вся дока — markdown в `docs/`. GitHub рендерит каждый `.md` при
просмотре репо, относительные ссылки между файлами работают — для релиза `0.1.0`
этого достаточно. Но это не «сайт»: нет сайдбара, нет поиска, нет своей темы и
домена.

Цель — отрендерить `docs/guide/` + `docs/api/` в полноценный сайт. Деплой и
домен должны быть «не гемор»: подключил репозиторий один раз → дальше авто-сборка
на каждый push.

## Текущее состояние

- `docs/guide/` — 8 страниц гайда (getting-started, contracts, server, client,
  mcp-and-agents, realtime, auth-and-errors, testing-and-deployment).
- `docs/api/reference.md` — полный API-reference по entrypoint'ам.
- Все ссылки в этих файлах — **относительные**, поэтому на любой генератор
  (Starlight / VitePress / Nextra) markdown переезжает почти 1:1.

## Варианты

| | Деплой | Домен | Tailwind / тема | Цена | Lock-in |
|--|--------|-------|-----------------|------|---------|
| Mintlify (hosted) | ноль — сами билдят | custom включён даже на free | ❌ только config + CSS | free Hobby / OSS-program 90% off | да |
| **Starlight + Cloudflare Pages** | connect один раз → auto на push | `*.pages.dev` free, custom — 1 CNAME | ✅ официальная Tailwind-интеграция, override любого компонента | $0 навсегда | нет |
| Nextra + Vercel | connect один раз → auto на push | `*.vercel.app` free, custom — 1 CNAME | ✅ Tailwind нативно (Next.js) | $0 hobby | средне |

### Mintlify

Hosted-платформа. Push в GitHub → они билдят и хостят. Красиво из коробки (на
нём Anthropic, Cursor, Resend, ElevenLabs). Минус — нет полного Tailwind (только
config темы + custom CSS), формат MDX + их компоненты (`docs.json`), vendor
lock-in. Markdown пришлось бы переписывать под их структуру.

### Starlight + Cloudflare Pages — рекомендуемый

Astro Starlight — генератор от команды Astro. Лучшая производительность
(zero-JS, <50KB на страницу), отличная дока-тема из коробки, полная свобода:
официальная Tailwind-интеграция, override любого компонента. Живёт отдельным
Astro-проектом, не навязывает ничего стеку. Cloudflare Pages: подключить репо
один раз → auto-build на push, free SSL, бесплатный субдомен `*.pages.dev`.

### Nextra + Vercel

Nextra — генератор на Next.js (на нём shadcn/ui, SWR, документация Vercel).
Tailwind нативно. Минус — тяжелее (Next SPA, 100–200KB JS) и тащит Next-стек,
которого в проекте иначе нет.

## Рекомендация

**Starlight + Cloudflare Pages.** Закрывает оба требования: «деплой не гемор»
(connect-репо-один-раз + auto-build) и «своя тема + Tailwind» (Mintlify это
режет — у него нет Tailwind). $0, без lock-in, мой markdown переезжает почти как
есть.

Mintlify — только если тема/Tailwind не важны и нужно «вообще ничего не
настраивать».

## Что надо сделать (Starlight-путь)

1. `packages/docs` — Astro + Starlight проект в монорепо.
2. Перенести `docs/guide/*` и `docs/api/*` в `packages/docs/src/content/docs/`,
   добавить frontmatter (`title`) на каждый файл.
3. Конфиг сайдбара в `astro.config` — порядок страниц гайда + раздел API.
4. Tailwind-интеграция, если нужна кастомная тема (лого, цвета stitchkit).
5. Cloudflare Pages: подключить репозиторий, build command + output dir — один
   раз.
6. Домен: `stitchkit.pages.dev` бесплатно сразу, либо купить `stitchkit.dev`
   (Cloudflare Registrar, по себестоимости ~$12/год) — одна CNAME-запись.

Решить при проработке: держать `docs/` как единственный источник и
синхронизировать в `packages/docs`, либо перенести страницы целиком в
`packages/docs` и оставить `docs/` только под `decisions/`, backlog и vision.
