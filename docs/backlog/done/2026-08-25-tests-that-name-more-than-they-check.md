# Тесты, которые называют больше, чем проверяют

## Зачем

Правило репозитория: закрытая задача может заявлять покрытие только назвав файл
и конкретный тест. Названы они верно — но три из названных проверяют не то, что
в их заголовке.

**Тест про порог простоя не может упасть по первому пункту.** Он подписан
«Points 1 and 2, and the reason this file exists», но с `heartbeatMs: 250`
проходит и при полностью удалённом `applyIdleTimeout`. Пробники против
`createServer`, по 12 секунд молчания каждый:

| конфигурация | итог |
| --- | --- |
| пульс 250 мс, **без** `server.timeout()` | выживает |
| `server.timeout(req, 0)`, **без** пульса | выживает |
| ни того, ни другого | умирает: `request timed out after 10 seconds` |

То есть каждая мера по отдельности достаточна в пределах процесса, и ни один
тест не заметит, если `applyIdleTimeout` станет пустышкой. А это правдоподобная
регрессия: функция утино-типизирована через `Reflect.get(server, 'timeout')` и
намеренно глотает исключение, так что переименование в Bun отключит её молча.

**И это же опровергает утверждение, повторённое в трёх местах** (исходник,
CHANGELOG, гайд): «forgetting any one of them breaks the stream silently». Для
первого пункта это неправда, когда есть второй — по крайней мере в пределах
процесса, без буферизующего прокси. Пункты 2 и 3 несут нагрузку по отдельности;
пункт 1 в Bun перекрывается пунктом 2.

**Два теста межверсионного поведения — тавтологии про Zod.** Один утверждает,
что `z.object({stored: z.boolean()}).safeParse(конверт).success === false`;
второй — что `z.unknown().safeParse(x).success === true`. Оба истинны по
определению Zod и прошли бы при полностью удалённой фиче конверта. ADR 0106
ссылается на этот файл как на закрепление «обеих половин» межверсионного
последствия; он не закрепляет ни одной — он утверждает факты про Zod.

**Непокрытые ветки**, каждая из которых существует не просто так: нецелый
`idleTimeoutSeconds` (ради него и стоит `Number.isInteger`); `catch` внутри
`answerWithRejection` (бросающий колбэк пира); усечение issues по потолку;
граница «fire-and-forget остаётся локальным», которую ADR называет явно;
`optionalDependencies` в восстановлении catalog-ссылок — из четырёх секций
покрыты три.

## Результат

- Тест, который падает при отключении **только** снятия таймаута.
- Межверсионные тесты проходят через реальный производящий путь фреймворка, а
  не через `safeParse` рукописного объекта; либо, если это невозможно,
  утверждение ADR о доказательстве ослаблено до того, что действительно есть.
- Утверждение «забыл любой из трёх — сломалось молча» приведено к правде во всех
  трёх местах.
- Названные ветки покрыты.
