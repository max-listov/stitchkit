# Хвосты аудита: гейт может зависнуть и может себя обмануть

## Зачем

Пять мелких, но настоящих дыр, каждая из которых делает гейт менее честным.

1. **`PUBLIC_WEB_HOSTS` не дедуплицируется.** `claimedHosts()` в
   `web-surface-smoke.ts` только режет и тримит. Один и тот же хост, записанный
   дважды, проходит как «два адреса», и доказательство переносимости
   сравнивает адрес сам с собой — ложноположительный результат в проверке,
   которая существует ради одного факта.
2. **Смок дозванивается без таймаутов.** Предполётная проверка таймаут имеет,
   а сами чеки — нет: зависший endpoint превращает гейт в бесконечное
   ожидание вместо красного.
3. **`stopProcessGroup()`** (`lane-processes.ts:147`) снимает SIGKILL-таймер по
   выходу лидера группы, хотя потомок, проигнорировавший SIGTERM, может быть
   жив. Форс отменяется ровно в том случае, ради которого он заведён.
4. **`pinnedStitchkitRanges()`** обещает в комментарии «каждое место», а читает
   три секции: `optionalDependencies` и overrides мимо.
5. **`starter-manifest.test.ts`** создаёт `mkdtemp` и не убирает за собой —
   тест про уборку, который сам мусорит.

## Результат

- Дедупликация allowlist'а до подсчёта адресов; одинаковые записи не считаются
  разными.
- Один таймаут на всех дозвонах смока; зависание — красный гейт с адресом.
- Форс снимается по факту исчезновения группы, а не по выходу лидера.
- Сканер манифестов читает все секции, которые обещает.
- Тесты убирают свои каталоги.

## Acceptance

- [x] Зависший endpoint даёт красный гейт за ограниченное время.
- [x] `bun run verify` зелёный.
