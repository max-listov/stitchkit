# Мемо гейта знает дерево и тулчейн, но не знает, с чем разговаривают полосы

## Зачем

Кеш зелёного гейта (`scripts/gate-memo.ts`) ключуется по двум вещам: хеш
содержимого рабочего дерева и отпечаток тулчейна (`bun:x.y.z node:vN
platform/arch`). Для lint, typecheck и unit-тестов этого достаточно — их вход
целиком в дереве.

Для полос — нет. `test:agent-store-postgres`, `starter-lane` и
`consumer-lane` разговаривают с вещами, которых в ключе нет:

- **PostgreSQL** — версия сервера и то, на какой адрес указывает
  `STARTER_TEST_DATABASE_ADMIN_URL`;
- **браузеры Playwright** — ревизии, установленные на машине;
- **переменные окружения**, которыми параметризованы полосы.

Практическое следствие: обновили Postgres или браузеры — дерево не изменилось,
тулчейн не изменился, ключ прежний, и гейт **пропустит** прогон, который в
новых условиях мог бы не пройти. Это не гипотеза о будущем, а прямое
свойство того, что сейчас записано в ключ.

Разбор соседней задачи про supervised-полосу показал, что это не абстракция:
именно отсутствие `pm2` в отпечатке было решающим доводом против условного
запуска полосы — машина без `pm2` записала бы зелёный `verify`, а следующий
прогон на том же дереве, уже с `pm2`, увидел бы запись и пропустил проверку.
Побочный эффект принятого там решения приятен: запиненный `pm2` попадает в
lockfile, lockfile лежит в дереве, дерево входит в хеш — то есть **это
измерение закрывается само**. Остальные (версия сервера PostgreSQL, ревизии
браузеров, значения переменных) не закрываются ничем.

Масштаб честный: пропуск возможен только на неизменённом дереве, а любая правка
любого файла возвращает полный прогон, и CI остаётся единственным авторитетом
для публикации. То есть это не дыра в релизе — это дыра в локальном удобстве,
которая проявляется ровно в день апгрейда окружения.

## Результат

- В ключ входит то, с чем полосы действительно разговаривают, а не только то,
  чем они запущены.
- Дешёвость сохраняется: сбор отпечатка не должен стоить больше секунды, иначе
  он съест выигрыш, ради которого мемо существует.
- То, что в ключ не вошло, **названо** — в комментарии рядом с ключом, чтобы
  следующий читатель видел границу, а не догадывался о ней.

## Что сделано

### Code
- [x] `laneEnvironmentFingerprint()` в `scripts/gate-memo.ts`: версия сервера
      PostgreSQL и набор установленных браузеров. Postgres спрашивается **теми
      же двумя способами, что и полосы** — через `STARTER_TEST_DATABASE_ADMIN_URL`,
      а при его отсутствии через локальный `sudo -u postgres`; иначе на этой
      машине отпечаток был бы вечной константой `pg:unset`, то есть измерением,
      которого нет.
- [x] Отпечаток входит в ключ только у профилей, которые реально гоняют полосы
      (`usesLaneEnvironment`): быстрый профиль читает файлы и платить за
      измерение базы не должен.
- [x] Неизмеримое получает **собственный** маркер (`pg:unreachable`,
      `browsers:absent`), а не общий: недоступная база даёт другой ключ, то есть
      лишний полный прогон, и никогда — пропуск.
- [x] Стоимость измерена: **77 мс**.
- [x] Измерение супервизора не понадобилось: по решению соседней задачи `pm2`
      запинен в devDependencies, то есть лежит в lockfile, то есть уже входит в
      хеш дерева.
