# implement() fails first on a missing handler

## Зачем

`packages/core/src/server/implement.ts:27,72` читает `handlers[key]` без проверки и
прогоняет значение через недокументированный каст. Отсутствующий хендлер
регистрирует живой маршрут, который падает 500 при первом запросе, — тогда как
соседние проблемы того же класса (дублирующиеся маршруты, перекрытые маршруты)
ловятся на старте.

Это прямо противоречит принципу, который слой тулов формулирует про себя же:
«better a failed deploy than a tool that silently vanishes» (`tools/mcp.ts:47-50`).
Контракт объявляет операцию, реализация её не несёт, сервер поднимается — и узнаёт
об этом пользователь.

## Результат

- Неполная реализация контракта не поднимает сервер.
- Сообщение называет сервис и операцию.
- Каст, скрывавший пробел от компилятора, исчезает вместе с ним.
