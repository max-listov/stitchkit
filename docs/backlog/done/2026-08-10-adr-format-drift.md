# ADR format drift

## Зачем

Перепись по 69 файлам `docs/decisions/`: доминирующая форма — `# ADR NNNN — …`,
затем `- **Status:**` / `- **Date:**`, затем Context / Decision / Alternatives /
Consequences. `Context` присутствует в 67 файлах из 69, `Consequences` — в 68.

Пять решений написаны иначе: 0060, 0061, 0066, 0067 и 0068 — без префикса `ADR`
в заголовке, со `## Status` отдельной секцией и `status: active` вместо
`accepted`; у **0068 секции Context нет вовсе**. При этом 0062–0065 писались в ту
же неделю в доминирующей форме, то есть это расхождение, а не смена стандарта.

Практический эффект небольшой, но реальный: форма ADR — это то, по чему читатель
(человек или агент) ориентируется, где искать обоснование. Отсутствующий Context
у 0068 означает, что самое свежее и самое крупное решение не объясняет, из какой
ситуации оно выросло.

Задача заведена как **наблюдение с развилкой**, а не как поручение переформатировать:
ADR неизменяемы, поэтому массовая правка формы — сама по себе решение, которое
надо принять осознанно.

## Результат

- Принято и записано решение: либо форма канонизирована в `CONTRIBUTING.md`
  (и расхождения оставлены как есть, потому что ADR не переписывают), либо
  выбранная форма приведена к единой в отдельном заходе.
- У 0068 появляется Context — независимо от выбора по остальным.
