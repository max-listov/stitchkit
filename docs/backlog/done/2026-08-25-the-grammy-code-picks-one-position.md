# Про grammY-код документ и реестр говорят разное

## Зачем

`grammy.ts:119` объясняет, почему `GRAMMY_WEBHOOK_NOT_ACCEPTING` **намеренно**
не входит в `STITCH_ERROR_STATUS`: реестр принадлежит generic-ядру (→ ADR 0002),
и имя провайдера не место в union, который импортирует каждый потребитель.
`errors.ts:136` этот код содержит — я добавил его, брендируя ошибку, и старый
комментарий не тронул.

Две позиции рядом хуже любой одной из них: следующий читатель не знает, какая
действует.

Аргумент за включение: гейт полноты существует ровно потому, что код, который
фреймворк бросает и которого нет в реестре, уезжает на провод в написании
stitchkit мимо `codeMap` и `unmappedCode`. Аргумент против: ADR 0002 и имя
провайдера в общем union.

## Результат

- Выбрана одна позиция, и выбор записан там, где он проверяется: либо код
  остаётся в реестре и комментарий переписан, либо код исключается, а гейт
  полноты получает явное правило для кодов адаптеров провайдеров.
- Решение уровня архитектуры — значит ADR, а не комментарий.
