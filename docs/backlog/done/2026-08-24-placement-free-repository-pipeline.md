# Конвейер — репозиторий перестаёт знать своё место

## Зачем

Индекс программы: восемь стадий, каждая — отдельный файл в этом же каталоге.
Здесь только порядок, зависимости и границы между стадиями, потому что две
из них правят один и тот же код.

## Словарь

Принят целиком, применяется во всех стадиях:

- **source** — снимок исходника с собственной идентичностью; git-коммит —
  частный случай, незакоммиченное дерево запечатывается снапшотом;
- **build** — переход `build(source, объявленные входы) → artifact`;
- **artifact** — байты, полученные сборкой; о месте они не знают;
- **bind** — переход `bind(artifact, bindings) → deployment`;
- **binding** — значение, которое место поставляет по имени, объявленному
  репозиторием: порт, домен, путь, окружение, платформа;
- **deployment** — artifact, связанный с bindings и работающий на ноде;
- **release** — глагол «привести deployment к source».

**Правило границы.** Если поле нельзя заполнить, не зная, куда поедет код, —
это binding, а не декларация. Декларация обязана быть полной и осмысленной,
когда не существует ни одной ноды.

## Фазы

### Фаза A — один источник схемы (S1)

Пока схема декларации не имеет единственного дома, любая новая клавиша
удваивается: сегодня `ApplicationIdentitySchema` уже существует дважды —
`packages/create-stitchkit/src/identity.ts:13` и
`packages/create-stitchkit/template/packages/config/src/identity.ts:4`.
Расширять дубль нельзя, поэтому это первая стадия.

- **S1** — `2026-08-24-manifest-schema-single-source.md`. Зависимостей нет.

### Фаза B — артефакт перестаёт знать своё место (S2)

Идёт параллельно A и **обязана предшествовать** любому обещанию герметичной
сборки с переносимым артефактом: сегодня сборка шаблона вмораживает внешний
origin в prerender (доказано, см. стадию). Пока это так, «один артефакт на два
deployment'а» физически невозможен, чем бы ни была декларация.

- **S2** — `2026-08-24-placement-seam-in-template.md`. Зависимостей нет.

### Фаза C — декларация (S3)

- **S3** — `2026-08-24-project-declaration-manifest.md`. Зависит от S1.

### Фаза D — то, чего декларация ещё не умеет (S4, S5, S7)

Три независимые друг от друга стадии, все зависят от S3. Каждая найдена
применением правила границы к конкретному файлу, а не выведена из теории.

- **S4** — `2026-08-24-role-port-and-bind-contract.md`: роль веба получает порт
