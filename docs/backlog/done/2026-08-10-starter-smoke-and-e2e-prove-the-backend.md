# Starter smoke and e2e prove the backend

## Зачем

**Мандатный гейт ломается на первой же фиче.** `template/scripts/runtime-smoke.ts:17-19`
бросает, если существует хоть один путь `/api/`. При этом `template/AGENTS.md:44-49`
предписывает смоук запускать, а `docs/ADDING_A_FEATURE.md` §6 нигде не говорит убрать
guard. Пример его молча удаляет — значит несовместимость известна, но не описана.
Пользователь, идущий по инструкции шаблона, получает красный обязательный гейт
ровно за то, что сделал первую фичу.

**e2e ничего не доказывает про бэкенд.** Ни одного вызова `createClient` или `fetch`
вне `env.ts`; `test` не включает e2e; `bun run e2e` не входит ни в один
документированный гейт. То есть браузерная полоса, самая дорогая часть прогона,
проверяет только фронтенд.

## Результат

- Смоук переживает добавление первой фичи и остаётся содержательным.
- e2e делает хотя бы одну сквозную проверку «браузер → API → ответ».
- Оба входят в документированные гейты.
