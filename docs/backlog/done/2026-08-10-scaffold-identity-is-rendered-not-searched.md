# Scaffold identity is rendered, never searched

## Зачем

**Сначала governance.** ADR 0066 (`status: active`, принят 2026-08-08) в строках
36-38 говорит прямо:

> The scaffolder performs a structural copy plus the required dotfile renames. **It
> does not rewrite project identity.** Consumers rename the neutral application
> explicitly when adopting it.

`create-stitchkit` 0.2.0, выпущенный 2026-08-10, ровно это и делает: `app.config.json`,
флаг `--display-name` и четыре перезаписи. Замещающего ADR нет, 0066 не помечен
superseded, а `grep` по всем 68 решениям не находит ни `app.config.json`, ни
`displayName`. То есть выпущенный код противоречит действующему решению, и первым
шагом задача обязана это разрешить — либо ADR о новой модели, либо откат фичи.

**Теперь механика.** Из четырёх мест только одно неустранимо.

| Артефакт | Сейчас | Нужно ли |
|---|---|---|
| `package.json` `name` | `JSON.parse` → мутация `any` | **Да, неустранимо** — читается пакетным менеджером до исполнения кода |
| `bun.lock` root `name` | регекс | **Нет.** Поле инертно (см. ниже) |
| `.env` / `.env.example` имя БД | `replaceAll` | **Нет** — место этому внутри сгенерированного проекта |
| `README.md` | не патчится вовсе | Живой дрейф |

Замеры на копии настоящего шаблона: при подстановке всё работает, а при дрейфе
шаблона `bun.lock` и `.env` **молча остаются старыми** (выход 0, без предупреждения).
Присваивание `manifest.name` при этом безусловное и на переименовании не
промахивается — у него дыра другая: манифест, распарсившийся в массив, даёт
`name = undefined` и выход 0.

**Решение владельца принято:** фича переименования сохраняется, откат не
рассматривается. Нужен новый ADR, который supersede-ит 0066 в соответствующей
части, объявляет derived identity основным механизмом и сводит число структурных
проекций к минимуму.

**Про `bun.lock`.** Bun 1.3.14 root `name` не валидирует и не чинит:
`--frozen-lockfile` проходит при рассинхроне и на обычном пакете, и на
workspace-корне. Поле инертно, поэтому по принципу «минимум проекций» перезапись
**удаляется**: дублировать источник имени проекта ради инертной метаданной строки
дороже, чем жить с нейтральным именем внутри лока.

**README доказывает, почему assert на замены не решение.** Его никто не патчит,
поэтому каждый сгенерированный проект уезжает с `# Stitchkit Starter` первой
строкой. Ручной список подстановок fail-open в обе стороны: он и промахивается
молча, и никто не перечисляет, что в него должно было войти. Никакая проверка трёх
существующих регексов README бы не поймала.

**Последствие дрейфа `.env` не косметическое.** При разъехавшемся шаблоне все
сгенерированные проекты получают одно имя БД, и `bun run db:setup` во втором
проекте накатывает миграции поверх данных первого. Покрытия у этой подстановки нет
вообще: `starter-lane.ts:239` перезаписывает `.env` целиком раньше, чем кто-либо
его прочитает, а юнит-тест работает на синтетической фикстуре.

**Правильная модель — «идентичность рендерится, а не ищется».** Каждое вхождение
относится ровно к одному виду: **derived** — файл импортирует `appIdentity`
(отсутствующий импорт даёт ошибку компиляции, испорченный конфиг — ошибку Zod при
старте); **projected** — только там, где в нужный момент импортировать нечего,
адресуется структурно (JSON pointer, ключ env), и нерезолвящийся адрес бросает. У
структурного сеттера нет состояния «совпало 0 раз».

Шаблон, кстати, уже почти весь derived: `app.config.json` кормит MCP `serverInfo`,
заголовок OpenAPI, имя и версию CLI, `SITE_NAME`, ключ темы, имена процессов pm2 в
обоих ecosystem-конфигах, баннер `dev`, каталог сертификатов LAN и ассерты e2e.

**Мелочь того же файла:** `scaffold.ts:136` вычисляет расширение как
`sourcePath.slice(sourcePath.lastIndexOf('.'))`, поэтому у имени без точки
«расширением» становится последняя буква. Сегодня латентно (единственные бесточечные
файлы спасает `|| targetName`), но безвредна не всякая ветка: незарегистрированный
`*.append` вычисляет расширение `.append`, читается как `Uint8Array` и умирает с
обманчивым «Append template entries must contain text». Классифицировать надо по
`extname()` **разрешённого выходного пути** — после переименования и снятия `.append`.

## Результат

- Решение о владении идентичностью записано ADR; 0066 либо помечен superseded в
  соответствующей части, либо фича приведена к нему.
- Единственная файловая проекция — `name` в корневом `package.json`, и читается он
  через схему, а не через `JSON.parse` в `any`.
- `bun.lock` и `.env` скаффолдер не трогает; имя БД рендерится внутри
  сгенерированного проекта из `app.config.json`.
- Сгенерированный README не содержит имени шаблона.
- Дрейф шаблона обнаруживается тотальной проверкой, а не списком известных замен.
