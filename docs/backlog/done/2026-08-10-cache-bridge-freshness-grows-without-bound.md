# Cache bridge freshness map grows without bound

## Зачем

`packages/core/src/react/cache-bridge.ts:62,103` — `markFresh` вставляет записи, а
удаления нет ни по истечении окна, ни по потолку. Публичная поверхность моста —
`["connect","disconnect","markFresh"]`, то есть очистить извне тоже нельзя.

Замер: 200 тысяч ключей сущностей удерживают 24.1 МБ **после** истечения окна
свежести. Для долгоживущего SPA — монотонный рост: вкладка, открытая на рабочий
день и получающая события по сущностям, не отдаёт память никогда.

На серверной стороне ровно от этого существует `createSweptMap` с `MAX_BUCKETS`;
на клиентской аналога нет, хотя браузерная вкладка живёт дольше запроса.

## Результат

- Записи о свежести не переживают своё окно.
- Число записей ограничено потолком.
- У моста есть публичный способ сбросить состояние.
